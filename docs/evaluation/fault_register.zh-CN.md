## 状态说明

- **未修**：还没有处理。
- **已修待验证**：已改代码，但还没有在付费的新问法全量测试中验证。
- **已验证**：在之后至少一轮新问法测试中没有再出现。
- **部分缓解**：有改善，但仍会出现。
- **复发**：修过以后又出现了。
- **已定口径**：由用户决定，不再算作故障。

“步骤”指一道题从理解到给出答案的环节：①题意识别 → ②规划（选工具、定范围） → ③检索覆盖 → ④逐篇判定 → ⑤生成、校验与评分。
