## 五项要求的落实

| 要求 | 第一版行为 |
| --- | --- |
| Overview / Relationships / Records | 三个独立视图共用集合、赞助方、媒体和日期筛选。常用筛选默认展开，当前范围始终可见；收集检索词、历史标签在 More filters 中。 |
| 公司 × 媒体作为概览主图 | 矩阵显示完整筛选范围内所有类别的计数，包括零值。点击格子，旁边列出该公司／组织与媒体的文章。完整交叉表可展开或下载。 |
| 字体与留白层级 | 去除重复的卡片底色和边框；标题、统计数字、说明形成层级。图中数字水平显示，长名称换行。 |
| 颜色用途明确 | 矩阵的蓝色深浅表示数量；网络用固定颜色区分赞助方和媒体，选中节点有轮廓强调。来源、缺日期、历史标签限制仍用文字说明。 |
| 详情靠近操作 | 矩阵和网络右侧均有文章列表；窄屏放在图下方。文章标题直接打开已有详情页，查看正文、原始链接和可用归档。技术标识与收集检索词收进折叠区。 |

“Sponsor” 保留来源字段口径，包含公司、行业组织和会议。页面明确说明 CERAWeek 属于活动；此次没有把分类展示改写为经过核验的公司身份。

## 建议试用顺序

1. 打开 Overview，点击 **ExxonMobil × The New York Times** 的数字 **3**：侧栏应出现三篇文章。
2. 点击其中一个标题，查看存储正文和来源。返回 Data 后可继续浏览。
3. 在顶部选择 ExxonMobil：当前集合变为 **15** 条，旧矩阵选择被清除；切换 Relationships 和 Records 仍使用同一筛选。
4. 在 Relationships 使用 Focus 下拉框或点击图中对象，查看匹配文章；Clear 只清除关系视图的局部选择。
5. 在 Records 使用排序、分页与下载；标题就是详情入口。顶部 Clear filters 恢复整个集合。

- 非 live 测试：`python -m pytest -m 'not live' -q`，**538 passed**。
- 本轮 Python 文件及新增／更新测试的 Ruff 检查通过。

- 窄屏验证：390px 视口，标签页保持一行，宽图表和表格在自身区域内滚动，页面没有整体横向溢出。临时视口已恢复。

实际点击发现 Dash 的热图事件会省略对象形式的 customdata，已改为兼容原始 x/y 坐标并校验它们属于当前筛选快照；无效值不能扩大查询范围。回归测试覆盖真实事件格式、零值、分页和筛选隔离。

## 数据与边界

当前默认范围为 **263** 条合格记录，其中 **226** 条可检索，**22** 条日期未知。原文与向量索引没有因界面调整而重建；`sentence600-v1` 仍为 **556** 个片段。

宽矩阵在较小窗口内需要横向滚动；关系网络默认展示最高计数的 24 条边，并明确报告覆盖范围，可切换数量或聚焦对象。图表仍是来源字段统计，不表示所有权、支付金额或主张真实性。真实社交数据与客户对分类口径的验收仍待完成。
