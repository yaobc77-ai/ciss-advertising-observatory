# 大幅交互知识图谱：实现与验证

日期：2026-09-29。范围：本机 Data 界面与完整筛选范围的来源图谱；未推送 GitHub 或部署 Railway。

## 结果与试用

[打开本机 Data](http://127.0.0.1:8050/data)，默认进入 **Knowledge graph**。选择 **Expand view** 放大画布；用 **Find a node or relationship** 搜索 ExxonMobil 或 The Washington Post，再选择节点或关系。旁栏提供精确数量、全部相邻对象与分页文章。文章标题进入正文与来源详情。

参考 [How Do They Lobby 的网络页](https://howdotheylobby.org/graph/all/all/all/MA/lobbying/3/)与[实体详情](https://howdotheylobby.org/clients/MA_258/)的“总览 → 对象 → 支持记录”路径，实际站点核对见[参考研究](LOBBY_GRAPH_REFERENCE_20260929.zh-CN.md)。本项目使用自己的广告记录与关系含义。

## 从旧界面到本次实现

| 项目 | 本次行为 |
| --- | --- |
| 进入 Data | Knowledge graph 是首个默认视图；Overview 和 Records 继续可用 |
| 总览范围 | 当前筛选范围的全部实体与关联，未设置 Top-N 或五文章上限 |
| 大图操作 | 拖动、平移、滚轮／按钮缩放、Fit、Reset、展开与 Escape 退出 |
| 初始布局 | By type 将赞助方和媒体分组，长媒体名放在节点旁；另有 Network、Circle、Grid |
| 点选 | 突出关联线及计数，淡化其他连接；不重新排列已有节点 |
| 对象详情 | 精确记录数、所有关联对象及各自数量、十条一页的支持文章 |
| 文章路径 | Articles 展开选中对象的文章；没有对象时展示全选择的文章路径 |
| 来源细节 | 版本、材料、历史标注检查器移至下方折叠区，打开后才加载五文章页 |
| 导出 | PNG 导出当前图；JSON 导出完整筛选图及路径见证，不受局部展开影响 |

文章邻域里只在检查具体文章／源字段路径时显示标题，避免几十个长标题挤在一起。文章仍可从搜索列表和旁栏进入。展开／收起保留当前视口，**Fit** 将现有节点位置适配到新画布；普通点选和列表翻页保持位置及视口。原生折叠区通过 Dash 的公开状态接口同步真实展开状态，打开后才加载详细来源。

ExxonMobil 对应四家媒体、15 条记录；Washington Post 对应七个赞助方／组织类别、18 条记录；两者交叉为五条。完整、公司、媒体、交叉、已知日期、空结果六个范围均与现有交叉表一致。19 个非缺失赞助方名称与矩阵的 20 个类别不同：矩阵另外包含缺失值类别，图谱不造共同的 Unknown 企业。

汇总线的 `derived_source_association` 表示来源记录共同列出两端名称。每条线保留所有记录、版本和两条原始类型边的见证，能够回到文章路径。它不独立验证付款、合同或商业合作。分类法、组织归并、正式 CLAIMS 与外部事实验证仍需要另外的证据与接入。

## 工程路线

`Database.knowledge_map_rows` 在只读 SQL 快照中读取全部合格记录及当前版本的公开元数据；`Service.knowledge_map` 应用源链接配置；`knowledge_map.py` 复用已有的稳定身份和源字段关系，生成完整计数与路径见证。总览不读取正文／任意标注 payload，正文哈希仅作为存储版本引用。

画布复用来自标准包注册表的 `dash-cytoscape 1.0.2`，通过组件的元素、样式、布局、事件及图片导出接口渲染。参见 [Dash Cytoscape 属性文档](https://dash.plotly.com/cytoscape/reference)。Network 排版将文字尺寸计入节点间距，使用内置布局；没有引入新的图数据库或自行实现图形引擎。

每次点击仅接受节点／关系的规范 ID；后台重新读取当前筛选图，计数、成员和来源不信任客户端 payload。分页只改变侧栏，点击不输出新的元素或布局。图谱仅在 `/data`、原生广告、图谱视图启用时加载。

本次没有新增 MCP 工具。网页共用的数据 Service 为后续完整图工具留出入口；原七个 MCP 工具及模型路由保持原有契约，不能据此宣称其图谱工具已自动升级为全选择大图接口。

拖动与平移使用 Cytoscape 原生能力；此次浏览器通过键盘选择路径核对业务结果，没有对所有鼠标手势、设备或 PNG 下载文件做穷举验证。工程、浏览器和计数检查不等于客户已认可数据口径或页面易用性。
