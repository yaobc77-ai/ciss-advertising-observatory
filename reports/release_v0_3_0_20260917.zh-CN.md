## 2. 实际落地的检索改动

1. **句界分块已启用到主库。** `sentence600-v1` 使用现有 pySBD 句界与 cl100k token 预算，上限 600 token、目标重叠 100 token；普通句子完整保留，超预算长句才使用窗口。字符位置仍指向不可变原文。
2. **生成前去除重叠原文。** 同一来源版本的相邻或重叠区间合并，再建立短句引用候选；不混合不同文章、不同版本或中间缺失的正文。旧 chunk ID 仍用于最终引用定位。
3. **显式索引版本和原子切换。** 新旧 profile 独立保存成员；当前检索只读取活动 profile。切换前检查正文版本、完整 chunk 清单及向量齐备，旧片段不删除。
4. **回答期间的数据变化会阻断发布。** 生成前后均比较包含索引版本的数据标识；发生变化时保存失败和费用审计，不展示可能已经过时的回答。

本轮没有加入元数据 embedding 前缀、自动问题翻译、重排序器或 HNSW。当前任务落实的是句界切分、上下文去重及可回退发布。

| 指标 | 发布前 | 发布后 |
|---|---:|---:|
| 收录记录 | 275 | 275 |
| 默认可统计记录 | 263 | 263 |
| 可检索正文 | 226 | 226 |
| 活动索引片段 | 558（legacy600-v1） | 556（sentence600-v1） |
| 保存的引用数量，含历史 | 180 | 185 |
| 原文版本／正文哈希清单 | 基线 | 均未变化 |
| 保存引用定位失败 | 0 | 0 |

185 条是历史 180 条加本轮 5 条；不是 185 道质量测试。旧 558 块索引已确认正文快照匹配、向量缺失为零，当前可回退；本轮没有实际来回切换生产索引。

版本分别为：

```text
source_data_version = 5114ebc1cf9afe59cdaa715e3ea45166
active_profile      = sentence600-v1
index_version       = d580c5962a6222e595db2ed8681f9787cef648dad653b055120b6bed10e3af75
data_version        = f19d4d697f4e6d2699d2c58b3ce80620b03e02c7e9447f24e012123adcb00f53
```

`source_data_version` 表示正文及记录状态；`data_version` 还包含索引状态。旧报告中的正文版本号继续有效，不应要求新旧综合版本相同。

## 3. 真实 API 与回答边界

| 工作 | 实际调用 | 应用账本费用（美元） |
|---|---:|---:|
| 补齐句界片段向量 | 437 个缺失文本，14 批 | 0.00422726 |
| 英文、中文开发题各运行一次 | 2 次生成 | 0.00135525 |
| 合计 | 16 次 | **0.00558251** |

查询向量复用已有缓存。无自动重试，预留均已结算；金额按项目配置价格和返回 usage 记账，未独立核对供应商账单。

两题共 5 条引用均可在原文版本和字符位置定位，各题的两条既定目标引文均被覆盖。**这不能证明新切分提升准确率。** 题目已用于开发，也不是重新完成整个评价题库。

AI 抽查另发现：中文回答第一条写出了 Corpus Christi 与 Ingleside Energy Center，地点确实出现在检索到的同篇较长正文中，但未包含在所选的短引文内；两条回答还重复使用同一短引文。因而短引文对整条表述的支持仍不充分，不能标为逐条语义验收通过。没有针对这道题修改提示词或重复调用来隐藏问题。人工语义审查仍待完成。

```powershell
.\.venv\Scripts\python.exe -m observatory.cli index-activate legacy600-v1 --expected-source-version 5114ebc1cf9afe59cdaa715e3ea45166
```
