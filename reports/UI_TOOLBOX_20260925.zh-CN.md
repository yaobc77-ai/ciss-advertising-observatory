# 首页精简与工具箱

按用户提供的截图继续精简首页：保留集合选择、问题输入和 Generate answer 主按钮；移除介绍句、空结果提示和页脚状态文字。默认没有额外筛选时不显示重复的当前范围文字，实际筛选、跨集合范围、错误和旧结果提示继续呈现。

右上角 Tools 图标打开原生折叠面板，集中提供：

- Query 的检索范围与关键词搜索。
- Query / Data 共用的媒体、赞助方、采集词、历史标签和日期筛选。
- API 预算及输入长度说明。
- 项目线框图入口。

Data 使用完整页面宽度。记录详情页沿用工具箱外观，提供查询、数据和线框图入口。没有添加未实现的功能或新的前端依赖。

工具箱可通过图标、关闭按钮或 Escape 关闭；执行检索和导航时自动收起。下拉框的第一次 Escape 只关闭下拉框。筛选控件保留唯一 ID 和原有会话状态，仍只有明确点击搜索/生成按钮才调用服务。
