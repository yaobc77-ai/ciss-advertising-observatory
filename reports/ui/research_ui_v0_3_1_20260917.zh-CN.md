## 3. biogas 的实际结论

对 `carbon capture and storage biogas` 的免费搜索返回 5 个片段，其中没有 biogas；但在同一筛选范围的 **226 篇可检索文章、556 个片段**里，biogas 匹配 **3 篇文章**。

因此页面显示的是“该词存在于当前选择的其他记录中，但未进入本次返回片段”，不能说“库里没有 biogas”。carbon / capture / storage 分别匹配 115 / 61 / 66 条可检索记录。这些是按同一英文词干索引、同一快照逐词计数，不能加总为不同文章数，也不证明文章主题或主张真实。

全范围诊断不受前 50 个检索候选的限制。中文等不适用英文词项诊断的问题会显示诊断不可用，不作“正文没有”的判断。缺词只针对已纳入索引的正文区间，不包含缺失、未捕获或被排除文本。

## 4. 归档仍需要什么

| 当前 263 条可计数记录 | 数量 |
|---|---:|
| 已有公开在线归档 URL | 0 |
| 有经过身份与哈希核验的本地 PDF | 1 |
| 只有未核验的标题关联候选 | 254 |
| 没有核验附件或候选关联 | 8 |

上述四行中在线归档是一项单独指标；其余三行划分了本次记录集合。正文哈希、PDF 哈希、路径范围或版本不符时附件服务停止提供该文件。

本轮没有为其余记录新建截图、抓取外部归档或替客户完成 254 条身份裁决。后续可先用采集日志中的精确 URL、正文交叉比对和来源清单核验，再扩充附件注册表。公开站点部署时还需交付相应源文件与预览缓存；源码本身不包含私有归档。已核验 PDF-265 的第一页已生成 592×1400 的 PNG，网页显示预览并保留六页完整 PDF 的打开／下载入口；缓存生成命令见[运行指南](../docs/operations.md#已核验-pdf-与预览缓存)。
