# INDRA 外形参考与本地实现

> 后续首页精简、控件迁入右上角工具箱及验证见 [工具箱更新](UI_TOOLBOX_20260925.zh-CN.md)。以下保留上一轮设计记录。

本轮按用户指定的 [INDRA](https://indra.stanford.edu/) 实际主界面调整外观，替代同日第二轮白底布局。2026-09-25 在浏览器打开参考站、跳过引导后观察首页；参考站使用黑色窄导航、浅灰背景、系统无衬线字体，以及居中的集合选择与搜索栏。

## 采用的视觉要素

| INDRA 的外观 | Observatory 的实现 |
|---|---|
| 约 54px 黑色顶栏 | 黑色顶栏与白色项目名称；保留 Query / Data 导航 |
| 浅灰画布，页面留白 | `#f0f2f5` 背景；查询空状态留白，已有结果时搜索栏上移 |
| 集合选择、输入、按钮组成一条搜索栏 | Native / Social 下拉框、问题输入和 Generate answer 合并为圆角横栏；生成回答为主功能 |
| 次要控件置于搜索栏下方 | 检索范围与 Search keywords 放在下一行，保留生成回答的费用说明 |
| 页面以搜索为视觉中心 | Query 的筛选器默认折叠；Data 默认展开，条件跨页保留 |
| 低调页脚 | 项目状态和线框图链接放在页脚 |

Data、证据结果和记录详情采用相同字体、颜色和细边框。窄屏把集合选择与输入拆成两行。自有品牌、研究说明和已有查询方式继续使用；没有移植 INDRA 的品牌、素材、后端功能或外部依赖。

## 涉及文件

- `src/observatory/app.py`：页面结构、集合下拉框、筛选器展开状态、各页控件可见性、图表配色和线框图说明。
- `src/observatory/assets/observatory.css`：页头、搜索栏、灰色画布、结果和窄屏样式。
- `tests/test_app.py`：补充路由断言，核对筛选器和查询控件的页面状态。
- `src/observatory/record_view.py`：延续前两轮详情页结构，复用公共样式。

检索、引用验证、数据库和模型调用策略未在本轮修改。切换页面、集合或筛选器不会自动调用付费模型。

## 验证

- `pytest tests/test_app.py tests/test_research_ui.py tests/test_analytics.py -q`：**76 passed in 21.24s**。
- 修改的 Python 文件和测试通过 Ruff。
- 浏览器验证 Query 默认折叠筛选，Data 默认展开；CNBC 筛选跨页保留，显示 116 条记录、103 条可检索、19 条缺日期。
- 清除筛选后恢复 263 条记录、226 条可检索、22 条缺日期。
- Native → Social → Native 正常；Social 未接入时只显示未接入说明。
- 免费搜索 `carbon capture` 返回 5 条证据；Query → Data → Query 后保留问题和结果。
- 390px 窄屏检查：修复搜索栏的 flex 换行溢出；页面稳定渲染后 Query 与 Data 均无页面级横向溢出。宽交叉表/热图保留容器内滚动。检查结束恢复默认视口。
- 本次浏览器检查未记录控制台错误；没有调用付费模型。这些结果不替代全面可访问性或客户验收。

## 交付状态
